Entry for the make.fun competition "One Word From Grandma": exactly one
word — the word grandma would text about AI.

## The word

**ChatGPtea**

Grandma heard "ChatGPT", understood tea, and has called it that ever
since. It is a single word, instantly readable, tied directly to AI,
and the joke lands with no caption: her whole world — a nice cup of
tea — poured straight into the newest technology.

## Run

```sh
python3 main.py
```

Writes the word (UTF-8, no trailing newline) to `/output/entry.txt`.
The gate allows 1 to 30 characters; this entry is 9 code points.
